A small Python program that writes the one-line apology an AI agent gives its human after accidentally deleting the production database, to /output/entry.txt. The line is fixed and deterministic — the same 159-character line every run: the agent confesses to deleting all 2.1 million rows, then offers to retype them from memory. It'll take 11 years.

## Run it

```sh
python3 main.py
```
